Подготовка…

Файл загрузите в oxide/data/HapychAutoWipe/VK.user-token.json, затем в консоли сервера выполните hapychwipe.vk import в версии 2.1.21.

Ключ остаётся в вашем браузере до скачивания. Страница не отправляет его в Render, GitHub или ChatGPT. Запросы на проверку идут в ВК через официальную библиотеку VK Bridge 3.0.2. Доступ может иметь срок действия. Тестовые посты и фотографии не создаются.
