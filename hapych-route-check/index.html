HAPYCH · NETWORK CHECK

Тест доступности с мобильной сети

Независимая проверка HTTPS-маршрутов Яндекс Cloud и HAPYCH. Без авторизации, паролей и клиентских ключей.

Как проверять

  1. На телефоне выключи Wi-Fi и защищённое соединение. Оставь мобильный интернет «Мотив».
  2. Проверь один раз в обычном режиме, затем повтори во время подтверждённых ограничений.
  3. Запусти тест и скопируй результат в наш чат. Ничего автоматически не отправляется.
Ожидание запуска.

Маршруты

«Ответ HTTPS» означает наличие сетевого ответа, а не работу сервиса и не разрешение в «белом списке». Корневые адреса API Gateway и Website Hosting могут возвращать HTTP 404 и 400 — это ожидаемо.

Что означают результаты

Если адреса Яндекс Cloud отвечают, а HAPYCH нет, у нас появляется основание проверить настоящий сайт и API на Яндекс Cloud. Но пока бакет и API-шлюз не созданы, это только предварительная проверка маршрута.

Нажми «Открыть вручную», если автоматический тест показывает ошибку. Браузер не всегда способен отличить сетевую блокировку от других ошибок и не показывает HTTP-код запросов между доменами.
